# Политика конфиденциальности — «Экранный переводчик»

Дата последнего обновления: 22.11.2026  
Контакт для вопросов и удаления данных: screentranslator.app@yandex.ru

## 1. Общие положения

Настоящая политика конфиденциальности регулирует порядок обработки данных при использовании приложения «Экранный переводчик».

## 2. Собираемые данные

Приложение работает локально на устройстве пользователя. **Автоматическая отправка данных** не осуществляется.

По желанию пользователя можно отправить:
* Диагностический журнал (технические события, версии)
* Непереведённые текстовые строки

## 3. Цели обработки данных

Данные используются исключительно для:
* Исправления ошибок
* Пополнения словаря перевода
* Улучшения работы приложения

## 4. Порядок обработки

**Автоматической передачи** данных не происходит. Отправка осуществляется только после:
* Явного согласия пользователя
* Ознакомления с текстом сообщения
* Нажатия кнопки «Поделиться»

## 5. Хранение данных

Отправленные данные хранятся в почтовом ящике разработчика не более 12 месяцев или до момента их обработки.

## 6. Права пользователя

Пользователь вправе:
* Отказаться от отправки данных
* Запросить удаление своих данных
* Получить информацию об обработке данных

## 7. Безопасность

Приложение не собирает:
* Личные данные (имя, контакты, платёжную информацию)
* Идентификаторы устройства
* Содержимое экрана (кроме выбранных пользователем строк)

## 8. Изменения политики

О любых изменениях в политике будет уведомлено путём обновления данного документа и даты в шапке.

## 9. Контактная информация

По всем вопросам обращаться: screentranslator.app@yandex.ru
